# 🪞 SELFIE 2.0 (סלפי החדש) – מערכת מיפוי, רפלקציה ומחקר אורך טכנו-פדגוגי ו-AI מזווג

מערכת ווב מתקדמת שפותחה עבור **מכללת אורנים – תוכנית פריזמה**, המשלבת את מסגרת הכשירות הדיגיטלית האירופית (**DigCompEdu / SELFIEforTEACHERS**) עם **מודל כשירויות הבינה המלאכותית 2.0 למורים** של משרד החינוך, תוך תיקון יסודי של 6 כשלי החישוב והמתודולוגיה שנמצאו בכלי ה-SELFIE המקורי.

## 🔬 6 הכשלים המתודולוגיים והמתמטיים שתוקנו ב-SELFIE 2.0

1. **תיקון כשל המדגמים הלא-מזווגים (Paired Within-Subjects Pre–Post vs. Unmatched Cross-Sectional):**
   - **הבעיה ב-SELFIE הישן:** הכלי האירופי מנתק את זהות המשיבים מהדוח הקבוצתי, כך שהשוואת תחילת שנה מול סוף שנה השוותה אנשים מסוימים בהתחלה ($N_1$) לאנשים אחרים בסוף ($N_2$) ויצרה הטיית נשירה ובחירה עצמית חמורה.
   - **הפתרון ב-SELFIE 2.0:** כל משיב מקבל מזהה מזווג קבוע (`Paired ID` מגובב `PID-...`). הדשבורד המחקרי מחשב את השינוי ($\Delta_i = \text{Post}_i - \text{Pre}_i$), ממוצע ההפרשים ($\bar{\Delta}$), מבחן $t$ מזווג וגודל אפקט ($Cohen's\ d_z$) **אך ורק על משיבים שענו בשתי הפעימות ($N_{\text{paired}}$)**, ומפריד בשקיפות מלאה את הנושרים ($N_{\text{attrition}}$ – עם כפתור הפקת תזכורת לישיבת החוג) ואת המצטרפים המאוחרים ($N_{\text{late}}$).

2. **איזון משקולות התחומים (Balanced 6×3 Domain Weighting):**
   - **הבעיה ב-SELFIE הישן:** מתוך 32 שאלות, לתחום 1 (תקשורת ארגונית ומנהלות) היו **9 שאלות (28.1%)**, לעומת **3 שאלות בלבד (9.4%)** לתחום ההערכה ו-5 לתחום ההוראה.
   - **הפתרון ב-SELFIE 2.0:** 6 תחומים מאוזנים × 3 היגדי ליבה = **משקל שווה ומדויק של $16.67\%$ לכל תחום**.

3. **כיול סקאלת הציונים ($0\%\text{–}100\%$) ורצועות הרמות (`A1–C2`):**
   - **הבעיה ב-SELFIE הישן:** ניקוד $1\text{–}6$ חלקי $6$ גרם לכך שמי שענה `A1` בכל השאלות התחיל ב-$16.67\%$ (צמוד לסף `A2` ב-$20\%$), ומי שענה `B1` ב-31 מתוך 32 שאלות ורק בשאלה אחת `B2` קיבל $50.5\%$ והוכתר כ-**`B2` (מומחה)**.
   - **הפתרון ב-SELFIE 2.0:** נרמול אמיתי מ-$0\%$ עד $100\%$ (`A1=0%, A2=20%, B1=40%, B2=60%, C1=80%, C2=100%`) עם 6 רצועות סימטריות שוות ($16.67\%$ לכל רמה).

4. **הפרדה בין "עומק פדגוגי ו-AI בהוראה" לבין "הובלת עמיתים בארגון":**
   - מאפשרת למרצה מצטיין שמיישם פדגוגיית עילית בקורסים שלו להגיע לרמות `C1–C2` בציר הפדגוגי גם אם אינו בעל תפקיד הדרכתי/ניהולי בסגל.

5. **החרגת "לא רלוונטי לתפקידי/לקורס" (`N/A`) מהמכנה:**
   - בניגוד לאופציה ה-7 ב-SELFIE הישן שמעניקה 0 נקודות ומורידה את הממוצע, סימון "לא רלוונטי" מחריג את ההיגד ממכנה התחום ללא קנס מתמטי.

6. **התאמה ל-3 תפקידים (מרצה / סטודנט להוראה / מורה בשדה) ודו-לשוניות מלאה (עברית + English):**
   - פותר את חסם השפה שמנע מענה בחוג לאנגלית ומותאם למילוי של כ-10 דקות בישיבת חוג.
